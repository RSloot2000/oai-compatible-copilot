# Security Policy

## Supported Versions

Only the latest fork version is actively supported.

| Version | Supported          |
| ------- | ------------------ |
| 0.4.3   | :white_check_mark: |
| < 0.4.3 | :x:                |

## Reporting a Vulnerability

If you find a security vulnerability in this fork, do NOT open a public issue. Please report it privately via the [RSloot2000 fork's GitHub Security Advisories](https://github.com/RSloot2000/oai-compatible-copilot/security/advisories). Issues inherited from the original project can also be reported to [upstream](https://github.com/JohnnyZ93/oai-compatible-copilot/security/advisories).

We aim to respond within 48 hours. Keep it simple: just provide the reproduction steps and the potential impact.
